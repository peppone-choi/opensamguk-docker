# 로컬 fixture 백업·복구·버전 롤백

새 F fixture와 그 복구용 복사본에만 쓰는 전용 도구입니다.
[실행 순서·인계 JSON·전체 명령·실패 복귀](../tools/fixture-recovery/README.md)를 따릅니다.
기존 fresh 하네스·compose·nginx·F 모델은 수정하지 않습니다.

F 빌드/health/strict smoke, C0 USER01/02, 프론트 첫 GUI 뒤 Docker 소유 채팅과 C0가
유지보수 창을 인계해야 실제 실행할 수 있습니다. 인계 전에는 가벼운 fake CLI 회귀만
허용합니다. 현재 실제 백업·복원·서로 다른 버전 롤백·USER 관측은 **NOT_RUN**입니다.

전체 흐름은 일관된 F 정지·5볼륨/비공개 설정/이미지 보존, 새 자원 nonce에서 기존 앱
identity 그대로 복원, 서로 다른 B 버전의 실제 관측, 또 다른 nonce의 A 복귀·관측,
원래 F의 보존·재개입니다. 같은 이미지 재시작이나 dump/tar 검사만으로 전체 성공을
대신하지 않습니다. 원래 F/C/E나 기존 데이터를 SQL로 보정·초기화하지 않습니다.

누락 버전·손상·소유 불일치·실제 ENOSPC·health/USER 실패는 실패로 남깁니다.
비공개 파일·원본/실패 복사본·journal은 보존하고 자동 삭제·prune·원격 업로드를 하지
않습니다. 공개 결과는 식별값·상태·개수·검산만이며 점수나 완료 상태를 자동 변경하지 않습니다.
